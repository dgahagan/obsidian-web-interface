# Welcome to My Knowledge Base

This is your Obsidian vault published as a website using [Quartz](https://quartz.jzhao.xyz/).

## Getting Started

1. Add your markdown files to the `content/` folder
2. Run `npx quartz build --serve` to preview locally
3. Push to GitHub for automatic deployment

## Features

- **Full-text search** - Find anything instantly
- **Graph view** - Visualize how your notes connect
- **Dark mode** - Toggle between light and dark themes
- **Privacy controls** - Hide sensitive content from public builds

## Quick Commands

| Command | Purpose |
|---------|---------|
| `npx quartz build --serve` | Start local dev server |
| `NODE_ENV=production npx quartz build --serve` | Test production build |
| `npx quartz build` | Build for deployment |
